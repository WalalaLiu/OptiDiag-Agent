# Report Outline

## 一、开发背景

- 光学实验图像在采集中常见过曝、欠曝、离焦、偏轴、背景不均匀等问题。
- 学生往往能看到“图像不好”，但不容易快速判断原因和下一步调整方法。
- AI 智能体插件可以把图像分析、指标解释和实验指导结合起来。

## 二、设计与开发

### 平台/技术选择

- Python
- NumPy/Pillow 仿真与图像处理
- FastAPI HTTP 服务
- OpenAPI schema 用于智能体插件接入
- 后续可选 PyTorch 多任务模型

### 开发过程

- 基于夫琅和费衍射公式生成六类衍射图样。
- 显式注入十一类实验误差或噪声。
- 保存 PNG、JSON 和 `labels.csv`。
- 计算可解释指标。
- 通过规则诊断输出中文建议。
- 通过 `/analyze` 接口供智能体调用。

### 功能架构

- `simulation`: 衍射仿真和误差注入
- `analysis`: 图像质量和衍射指标
- `reasoning`: 规则诊断和中文报告
- `api`: FastAPI 插件接口
- `models`: 后续多任务模型骨架

## 三、应用过程与效果

- 上传衍射图像到智能体。
- 智能体调用 `/analyze`。
- 插件返回图像类型、问题、指标、诊断和建议。
- 展示典型案例：过曝、偏轴、离焦、背景不均匀、低对比度。

## 四、创新与反思

创新点:

- 不只做孔径分类，而是面向实验调整的误差诊断。
- 返回可解释指标，方便课程报告和智能体解释。
- 没有训练权重时也可通过规则诊断运行。

不足与展望:

- 第一阶段规则阈值需要真实实验图像进一步校准。
- 后续应训练多任务模型并加入真实图像验证。
- 可扩展到干涉图、光谱图和显微图像。
